# AI Voice Chat (Groq-Powered)

[Check it out!](https://mumitprottoy.github.io/voice-chat-ai/)

A blazing-fast AI voice chat interface in a single **5KB HTML** file — no installs, no bloat.

## 🚀 Features

* Instant voice interaction with AI
* Lightweight (just 5KB)
* Runs entirely in your browser
* Uses **Groq API** for fast responses

## 🛠️ How to Use

1. **Clone or download** this repo.
2. Open `tts.html` in your browser.
3. Paste your **Groq API Key** when prompted (get one [here](https://console.groq.com/)).
4. Start chatting with voice!

## 🔐 Privacy

All processing runs locally in your browser. Your API key and voice data are never stored.
